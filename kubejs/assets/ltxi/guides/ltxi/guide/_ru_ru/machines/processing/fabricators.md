# Технологическое изготовление

Некоторые улучшения и снаряжение слишком сложны, чтобы быть изготовленными на обычных станках или верстаке. Для этого вам понадобится Изготовитель (Fabricator). Рецепты изготовления уникальны среди всех типов рецептов LTXI, ознакомьтесь со спецификацией рецептов ниже.

## Спецификации рецептов
- Входы: 1-16 предметов
- Выход: 1 предмет
- Энергопотребление: варьируется в зависимости от рецепта, **используется вместо времени изготовления**

Из-за отсутствия времени изготовления, скорость Изготовителя является гораздо более простой функцией от энергопотребления рецепта и характеристики машины **Энергопотребление**. Вы можете считать это характеристикой с положительным значением для этой машины.

Также известный как ручной Изготовитель, это первая машина для изготовления, которую вы сделаете. Вы можете просмотреть доступные рецепты в сетке рецептов. Чтобы выбрать рецепт, нажмите левой кнопкой мыши один раз. После выбора нажмите левой кнопкой мыши еще раз, чтобы изготовить, или правой кнопкой мыши, чтобы закодировать рецепт в **Пустой чертеж изготовления**. У этого Изготовителя нет слотов входа, он берет ингредиенты непосредственно из вашего инвентаря для удобного изготовления.

## Авто-изготовитель
<BlockImage id="auto_fabricator" scale="2" />

Более специализированная версия Изготовителя. Он компенсирует недостаток разнообразия рецептов простотой автоматизации. В отличие от обычного изготовителя, он имеет 16 слотов входа для ингредиентов и не может брать их из вашего инвентаря.

### Операция на основе одного чертежа

Поместите кодированный чертеж изготовления в слот для чертежа, чтобы работать в этом режиме. Вы должны обеспечить правильное количество ингредиентов с помощью предпочтительного метода транспортировки предметов. Пока у него достаточно ингредиентов и энергии, он будет непрерывно изготавливать рецепт по чертежу.

### Интеграция с AE2 Pattern Provider
AE2 **Pattern Providers** имеют встроенную совместимость с Авто-изготовителем и кодированными чертежами изготовления. **Примечание! Слот для чертежа должен быть пуст, иначе Pattern Provider не распознает Авто-изготовитель как действительную машину для изготовления.**

- Чертежи — это шаблоны (patterns). Вставляйте их непосредственно в слоты шаблонов Pattern Provider, без необходимости в шаблонах для обработки (Processing patterns).
- Поддержка составных ингредиентов/тегов/замен по умолчанию.
- Блокирующий режим не нужен, подача предметов и чертежей управляется автоматически.
- Конфигурация входа/выхода предметов перенастраивается при каждой отправке шаблона. Он будет автоматически выводить на сторону pattern provider и отключать остальное.

## Совместимые улучшения

Устанавливаются через [Систему улучшений](../../fundamentals/upgrade_system.md).

- **Улучшенная инструментальная головка**: Макс. ранг 4. Умножает энергопотребление на 4 на 1 ранге, удваивая каждый ранг до 32x на 4 ранге, а также повышает емкость энергии и скорость передачи соответственно. Поскольку скорость Изготовителя масштабируется вместе с энергопотреблением, более высокие ранги работают быстрее.

> Подходит как для Изготовителя, так и для Авто-изготовителя. Ни один из них не является частью `#ltxi:upgradable/standard`, поэтому Σ/VM3 Блок питания им не подходит.
