# Атмосферный скруббер

<BlockImage id="atmospheric_scrubber" scale="4" />

## Совместимые улучшения

Устанавливаются через [Систему улучшений](../../fundamentals/upgrade_system.md).

- **Σ/VM3 Блок питания**: Макс. ранг 5. Каждый ранг сокращает время операции вдвое, а также увеличивает емкость энергии и скорость передачи. Потребление энергии удваивается с каждым рангом.
