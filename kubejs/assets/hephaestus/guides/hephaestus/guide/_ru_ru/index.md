# Hephaestus

Hephaestus плавит металл в жидкость и отливает его в формы. Вы начинаете с малого с Плавильни (Melter), а затем строите Литейный завод (Smeltery) для плавления в больших объемах.

## Мультиблоки

- [Литейный завод](smeltery.md): руководство по постройке и созданию структуры, с 3D примером.
